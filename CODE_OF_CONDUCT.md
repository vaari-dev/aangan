# Code of conduct

Aangan adopts the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Report conduct problems privately through [Security → Report a vulnerability](https://github.com/vaari-dev/aangan/security/advisories/new),
saying that it's about conduct. Reports are reviewed promptly and fairly, and the reporter's privacy is respected.
